# Подключение входа в «Соф»

Текущая версия — статический прототип. Все три способа входа явно обозначены как неподключённые. Приложение не отправляет SMS, не имитирует проверку кода и не сохраняет OAuth-токены. Имя, email и адрес в гостевом профиле сохраняются только локально в браузере; это не подтверждённая учётная запись.

Для рабочего входа нужен сервер авторизации и единая база пользователей. Нужны следующие настройки через кабинеты провайдеров и серверное хранилище секретов, не через публичный JavaScript или чат:

- Яндекс ID: зарегистрированное OAuth-приложение, client_id, client_secret и зарегистрированный callback URL. Сервер создаёт одноразовый state, обменивает authorization code на токен, получает подтверждённую личность и создаёт сессию.
- Телефон: выбранный SMS-провайдер и его серверные ключи. Сервер нормализует телефон, ограничивает запросы и попытки, хранит хеш короткоживущего одноразового кода и проверяет его перед созданием сессии. Отправка SMS оплачивается провайдеру.
- MAX: зарегистрированные бот и мини-приложение. Вход из MAX использует initData; сервер проверяет подпись с токеном бота и срок auth_date до создания сессии. Внешний сайт открывает зарегистрированное мини-приложение. Данные initDataUnsafe сами по себе не доказывают личность.

Сессии посетителей нужно реализовать через защищённые Secure/HttpOnly cookies, серверные операции — с защитой CSRF и ограничением запросов. Связывание двух провайдеров с одним профилем требует подтверждения обеих личностей. Smartofood исключён: сервис не поддержал размещение нашего интерфейса. Собственный вход владельца и управление меню реализованы отдельно; см. ADMIN-README.md. Вход посетителей через провайдеров по-прежнему не подключён.

## Категории и отклик

Позиции вычисляются по окружности: x=R·sin(θ), y=R·(1−cos(θ)), R=1.35·ширина, угловой шаг 0.17 рад. Круг фона использует тот же R. Pointer Events управляют поворотом, после отпускания идёт плавное выравнивание; доступны колесо мыши и стрелки клавиатуры. Предпочтение reduced-motion отключает анимацию. Звук синтезируется Web Audio после пользовательского жеста. Вибрация вызывается через navigator.vibrate при поддержке браузером; на всех устройствах она не гарантируется. Звук и вибрация отключаются в профиле.
