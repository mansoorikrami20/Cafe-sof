# Кафе «Соф»

Добавлена настройка реквизитов iiko по филиалам в разделе «Подключения»: зашифрованное серверное хранение, замена, отключение и проверка авторизации/организаций. Требуется серверная sensitive-переменная `SOF_INTEGRATION_SECRET`. Импорт меню и реальные заказы ещё не подключены. Подробности — в `ADMIN-README.md`.

Собственный интерфейс заказа еды и кабинет управления меню сети «Соф».

- Меню: https://sof-cafe-preview.vercel.app/
- Админка: https://sof-cafe-preview.vercel.app/admin
- Требования и состояние: [docs/PROJECT.md](docs/PROJECT.md).
- Правила работы с кодом: [AGENTS.md](AGENTS.md).

## Быстрая проверка

Нужен Node.js 24:

```sh
npm ci --ignore-scripts
npm test
```

Фронтенд написан на HTML/CSS/JavaScript без сборки. Папка `dist/` содержит авторские исходники интерфейса и отслеживается Git. Серверные функции Vercel находятся в `api/`, общие серверные модули — в `server/`. Это уже существующий проект: не заменяйте его новым шаблоном.

## Текущее состояние

Реализованы мобильный интерфейс, корзина и демонстрационное оформление, профиль гостя, кабинет владельца, блюда и товары, отдельные категории, цены, фото, стоп-листы, остатки товаров, настройки четырёх филиалов и резервные копии. Исходный каталог содержит 45 позиций по TXT; уже сохранённый каталог можно дополнить из кабинета без перезаписи ручных цен. Для серверного каталога подготовлено закрытое хранилище Vercel Blob.

На момент переноса 22 октября 2026 года хранилище ещё **не привязано к проекту**, сохранение и регистрация владельца не активированы. Кабинет показывает явный предпросмотр. В текущей разработке добавлены каталог товаров и настройки четырёх филиалов с отдельными ценами и доступностью. Товары и реальные контакты заполняет владелец. Реальные заказы, база клиентов и интеграция iiko пока не реализованы. Наличие пункта в задании не означает готовую функцию.

## Развёртывание

Существующий проект Vercel: `sof-cafe-preview` (`prj_7VeK4nILzjDeZaWND9CBQ0AXXNWH`), команда `team_yb5mkjpkURaCDw2UsDRGKrT1`. Настройки находятся в `vercel.json`: Node-функции из `api/`, статические файлы из `dist/`.

В кабинете Vercel нужно привязать `sof-menu-admin` к `sof-cafe-preview` для Production и заново развернуть проект. Затем проверить `/api/manage?action=session` и настроить владельца через личную одноразовую ссылку. Значения секретов хранятся в Vercel, их нет в репозитории. Идентификаторы в документации не являются ключами доступа.

GitHub-репозиторий создан отдельно от текущего деплоя. Подключение автоматического деплоя из GitHub ещё не выполнено; перенос исходников сам по себе не меняет работающий сайт.

Перед продолжением разработки прочитайте [docs/PROJECT.md](docs/PROJECT.md): цены из TXT приоритетнее цен в PDF, дизайн уже согласован, реальные клиентские данные требуют отдельного серверного хранилища.

## Проверки перед выпуском

В этой ветке добавлены одноразовый код входа, проверка новых паролей по утечкам, уменьшение сбора данных в демонстрации и доступная информация об условиях. [Полная матрица изменений и оставшихся вопросов](docs/VIDEO-READINESS.md).

До публикации проверьте доставку писем через Resend и переменные SOF_PUBLIC_ORIGIN, SOF_EMAIL_FROM, RESEND_API_KEY. Код входа включён по умолчанию. Эти изменения исходников сами по себе не обновляют рабочий сайт. Окончательные юридические документы требуют реквизитов и условий исполнителя.
