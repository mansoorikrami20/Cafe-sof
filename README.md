# Кафе «Соф»

Собственный интерфейс заказа еды и кабинет управления меню сети «Соф».

- Меню: https://sof-cafe-preview.vercel.app/
- Админка: https://sof-cafe-preview.vercel.app/admin
- Требования и состояние: [docs/PROJECT.md](docs/PROJECT.md).
- Правила работы с кодом: [AGENTS.md](AGENTS.md).

## Быстрая проверка

Нужен Node.js 24:

```sh
npm ci --ignore-scripts
npm test
```

Фронтенд написан на HTML/CSS/JavaScript без сборки. Папка `dist/` содержит авторские исходники интерфейса и отслеживается Git. Серверные функции Vercel находятся в `api/`, общие серверные модули — в `server/`. Это уже существующий проект: не заменяйте его новым шаблоном.

## Текущее состояние

Реализованы мобильный интерфейс, корзина и демонстрационное оформление, профиль гостя, кабинет владельца, редактирование блюд и категорий, цены, фото, стоп-лист, настройки кафе, резервные копии. Для серверного каталога подготовлено закрытое хранилище Vercel Blob.

На момент переноса 22 октября 2026 года хранилище ещё **не привязано к проекту**, сохранение и регистрация владельца не активированы. Кабинет показывает явный предпросмотр. Реальные заказы, база клиентов, продукты, филиалы и интеграция iiko пока не реализованы. Наличие пункта в задании не означает готовую функцию.
