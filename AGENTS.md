# Cafe-sof: инструкции для Codex

## Начало работы

Прочитайте `README.md`, `docs/PROJECT.md`, `ADMIN-README.md`. Это существующий проект «Соф», не начинайте его заново. Сохраняйте согласованный интерфейс посетителя: фото без фона поверх карточек, пологая круговая карусель, увеличенные кнопки добавления.

## Источники

- `docs/sources/menu-prices.txt` — актуальные названия, цены, вес и количество. Цены из этого файла имеют приоритет перед PDF и макетами.
- `docs/sources/cafe-requirements.txt` — исходные требования к четырём филиалам и доставке.
- Не придумывайте адреса филиалов, цены продуктов, состав блюд, фото и реквизиты iiko. Если нужно временное значение, явно обозначьте его в черновике и не публикуйте как реальные данные.
- Вопрос «от 1000 ₽ доставка» в исходнике неоднозначен. Не трактуйте его как стоимость доставки или минимальную сумму без подтверждения.

## Код и проверки

- `dist/` здесь является исходным HTML/CSS/JS интерфейса. Не удаляйте его как артефакт сборки.
- Сервер: `api/`, `server/`; тесты: `tests/`.
- Зависимости: `npm ci --ignore-scripts`. Проверка: `npm test`.
- Работайте небольшими законченными изменениями, проверяйте доступ и состояние хранилища, не обходите конфликты версий.
- Для публичных страниц и API не допускайте раскрытия клиентских данных, резервных копий с реквизитами, ключей и паролей.

## Доступ и честное состояние функций

- Не добавляйте обход входа владельца или регистрацию первого администратора без личного одноразового ключа.
- Не храните API-ключи, пароли и строки подключения в коде, Git, публичном JSON, localStorage или логах. Настраивайте их через серверное хранилище секретов.
- Обязательны серверная проверка прав и входных данных, защита запросов, контроль версий при сохранении.
- «Сохранено», «Заказ принят», «Интеграция подключена» допустимы только после успешного ответа соответствующего сервера. Недоступное подключение должно оставаться явно недоступным.
- Не записывайте реальные клиентские данные в демонстрационный каталог Vercel Blob: сначала подключите полноценную базу для клиентов/заказов.
- Не отправляйте тестовые заказы в iiko или на оплату без явно разрешённого тестового окружения/действия.
- Smartofood исключён: он не поддержал нужный интерфейс.

## Публикация

Сохраняйте существующие проект Vercel и домен. Перед публикацией проверьте тесты и соответствие целевой команды/проекта. Автоматический деплой GitHub пока не настроен. Не утверждайте, что сайт обновился, только на основании коммита в GitHub.
